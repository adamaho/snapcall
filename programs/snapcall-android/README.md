# Snapcall Android

A single-screen Android scaffold for Snapcall. It displays a welcome message
using the same Compose, Geist typography, and system light/dark theme patterns
as Goho. The screen works without a running server.

The project includes development/production variants and a generated Kotlin
client for the shared Snapcall health API. See [CONTRIBUTING.md](CONTRIBUTING.md)
for building, running, and regenerating the client.
